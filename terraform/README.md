# terraform — Day-2 reconcile state (data-driven, for_each)

Declarative desired-state for Day-2 policy via the `scm` provider. `plan` is the
PR preview and drift detector; `git revert` + apply is rollback. **One state per
SCM folder** — never one monolithic state.

```
modules/
  security_folder/     # the static, reviewed-once module (scm_* resources, for_each)
prod-edge/             # per-folder ROOT (one state): provider + backend + module call
  rules.auto.tfvars.json   # GENERATED by `fwgitops compile` (tracked — desired state)
```

**Output contract:** the compiler emits `rules.auto.tfvars.json` per folder; each
per-folder root auto-loads it into typed variables and passes them to the shared
`security_folder` module, which iterates with `for_each`. The module is authored
+ reviewed once; only the JSON data changes per request. `for_each` keys are the
compiler's stable keys, so editing one entry never churns the others.

**⚠️ Unvalidated against the live provider.** The variable types (compiler
contract) are correct; the `scm` provider resource/attribute schema is NOT yet
verified — see `modules/security_folder/README.md` for the spike checklist
(every `# VERIFY:` marker). Resolve those before the first `apply`.

**Setup:** fill in the remote backend (`prod-edge/backend.tf`, Arch-2 decision)
and provider auth (short-lived token, T1). Do NOT bulk-import the brownfield
rulebase; onboard scope greenfield-first (Premise 4).
